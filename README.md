### Rules

- Siempre instala las dependencias (de desarrollo o produccion) con la version exacta (pnpm add package -E o pnpm add package -DE)
- Importa los tipos primero, luego imports default y finalmente imports comunes, ordenado por longitud / alfabetico
- No edites la configuracion de eslint y evita siempre apagar las reglas en linea `/* eslint-disable... */`
